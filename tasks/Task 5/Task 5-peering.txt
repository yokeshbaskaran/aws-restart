## 🔹 Step 1: Create / verify Internet Gateway (IGW)

1. Go to **VPC Console → Internet Gateways**.
2. Create an IGW (e.g., `my-vpc-igw`).
3. Attach it to your VPC (`150.10.0.0/18`).

150.10.0.0/18
---

## 🔹 Step 2: Create route tables
1. **Public Route Table**

   * Go to **VPC → Route Tables → Create route table**.
   * Name it `Public-RT`.
   * Associate it with your VPC.
   * Edit **Routes** → Add:

     * Destination: `0.0.0.0/0`
     * Target: Your **Internet Gateway**

2. **Private Route Table**

   * Go to **Create route table** again.
   * Name it `Private-RT`.
   * Associate it with your VPC.
   * Leave the default local route only (no IGW).
   * (Optional: if you have a NAT Gateway, add route `0.0.0.0/0 → NAT Gateway` here.)
---

## 🔹 Step 3: Edit Subnet Associations

1. Go to your **Public-RT** → **Subnet Associations → Edit subnet associations**.
   * Select **`150.10.0.0/24` (your public subnet)**.
   * Save.
2. Go to your **Private-RT** → **Subnet Associations → Edit subnet associations**.
   * Select **`150.10.20.0/24` (your private subnet)**.
   * Save.

---

## 🔹 Step 4: Security groups & testing

* For EC2 in the **public subnet**, make sure its **security group** allows inbound SSH/HTTP/HTTPS (as needed).
* Assign a **public IP** (or Elastic IP).
* For EC2 in the **private subnet**, no public IP. Access it only:

  * From a bastion host in the public subnet, or
  * Through a NAT Gateway (for outbound internet).
