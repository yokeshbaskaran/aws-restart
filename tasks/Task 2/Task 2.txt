📌 1. EBS Snapshot Transfer :-
Steps: 
--------
1.  Launch Instance-1→ Create a Linux EC2 instance.
2.  Attach a new 10GB EBS volume→ from AWS console, attach to Instance-1.
3.  Format & Mount→ format it (`mkfs`), mount to `/data`.
4.  Make mount permanent→ add UUID entry in `/etc/fstab`.
5.  Add test files→ create `hello.txt`, `readme.txt` inside `/data`.
6.  Unmount→ ensures clean snapshot.
7.  Take Snapshot→ from AWS console → Volumes → Create Snapshot.
8.  Detach original volume→ detach from Instance-1.
9.  Launch Instance-2→ another Linux EC2.
10.  Create new volume from snapshot→ same AZ as Instance-2.
11.  Attach to Instance-2→ mount at `/data`.
12.  Verify files→ check that `hello.txt` and `readme.txt` exist.
13. (Optional)  Persist mounton Instance-2 using `/etc/fstab`.
14. (Optional)  Cleanupvolumes/snapshots to save costs.

 Instance-1 → Extra EBS → Snapshot → New EBS → Attach to Instance-2 → Files available there.
