In the **AWS EC2 console**, when you see **“3/3 checks passed”** for an instance, it means that your instance has successfully passed all three health checks that AWS performs:-

1. **System Status Check**
   * Verifies that the AWS infrastructure hosting your instance is working properly.
   * Example: Power, networking, and hardware in the Availability Zone.
   * If this fails, the issue is on AWS’s side.
2. **Instance Status Check**
   * Verifies that your EC2 instance’s operating system is reachable and responding.
   * Example: The virtual machine boots, responds to network pings, and the OS is accessible.
   * If this fails, the issue is usually inside your instance (e.g., OS crash, kernel panic, firewall misconfig).
3. **Instance Reachability Check** (sometimes called the **Instance Reachability Health Check**)
   * Ensures that your instance can be reached from the internal AWS network.
   * Checks that the instance's network stack is working and traffic can flow in/out as expected.

✅ **3/3 checks passed** means:
* The AWS infrastructure is healthy.
* Your instance’s OS is up and responding.
* The instance’s network is reachable.
	- Basically, it indicates your instance is in a **healthy and fully operational state**.

### 1. Public vs Private Subnet (VPC)
* **Public Subnet**: 
	A subnet that has a route to the internet via an **Internet Gateway (IGW)**. 
	EC2 instances here can be accessed directly from the internet (if they have public IPs).
* **Private Subnet**: 
	No direct internet access. 
	To reach the internet, resources must go through a **NAT Gateway/Instance** in a public subnet.

👉 **Why?** 
Separation improves security — public-facing apps in public subnets, databases in private subnets.


### 2. Inline Policy vs Role (IAM)
* **Inline Policy**: A policy directly attached to a single IAM user, group, or role (not reusable).
* **Role**: An IAM identity with permissions policies that **can be assumed** by trusted entities (like EC2, Lambda, or users).

👉 **Why?** Roles allow temporary credentials and are safer than embedding long-term keys.


### 3. Resource Pooling (AWS General)
	- In a single physical server, multiple resources can be launched like s3, ec2 instance, databases.
	- a different resources are available in single physical resources. we have pool of resources inside a hardware servers.
	- In **cloud computing**, resource pooling means AWS shares compute, storage, and networking across multiple customers using a **multi-tenant model**, while still isolating each customer securely.

👉 **Why?** Efficient use of hardware, scalability, and cost-effectiveness.


### 4. Key Pair (EC2)
	- it consists of a PUBLIC key (master key) stored in AWS and a PRIVATE key (customer key) are downloaded by you. It can be download only once when launching instance.
	- Used for SSH (Linux) or RDP (Windows) login to EC2 instances.
👉 **Why?** Secure access without passwords.

### 5. How Many Subnets in One VPC
	- Default: up to 200 subnets per VPC (default limit, can be increased when requested to AWS).

### 6. How Many VPCs per Region
	- Default quota: 5 VPCs per region (can be increased by request).

### 7. IAM - (Identity and Access Management) 
	- used for security and administration.
	- manages **users, groups, roles, and permissions**.
👉 **Purpose:** Control **who can do what** in AWS securely.

### 8. Difference: Region, AZ, and Edge Location
	- Region : A geographic area (e.g., us-east-1).
	- Availability Zone (AZ) : Isolated data centers **within a region** (for high availability).
	- Edge Location: Isolated from normal Data center from region. it is a Content delivery endpoints (used by CloudFront, Route 53) near users. it only stores the copies of original content (like a cache). We cannot store any data in here only receive the data from it.
👉 **Why?** Regions = location choice, AZs = redundancy, edge = low-latency content delivery.
-------
### 9. S3 vs EBS
* **S3 (Simple Storage Service)**: Object storage, unlimited, used for static files, backups, big data. Accessible via URL/API.
* **EBS (Elastic Block Store)**: Block storage, used as virtual hard disks for EC2. Limited to a single AZ.
👉 **Why?** Use S3 for scalable storage, EBS for EC2 persistent disks.
---
### 10. Scalability vs Elasticity
* **Scalability**: System can handle increased load by adding resources (vertical/horizontal).
* **Elasticity**: Automatic scaling **up and down** based on demand.
👉 **Why?** Scalability = growth-ready, Elasticity = cost-saving.
---
### 11. Direct Connect
AWS **Direct Connect** provides a **dedicated private network connection** between your on-premises data center and AWS.
👉 **Why?** Lower latency, higher bandwidth, more secure than internet VPN.
---
### 12. AMI (Amazon Machine Image)
An **AMI** is a pre-configured template for launching EC2 instances (OS + software + settings).
👉 **Why?** Faster and consistent deployments.
---
### 13. Snapshot (EBS)
A **snapshot** is a **point-in-time backup** of an EBS volume, stored in S3.
👉 **Why?** For backup, restore, and creating new volumes in same/different AZs.

 Part 1 – AWS Cloud Foundations**

**1. What are IaaS, PaaS, and SaaS?**

* **IaaS (Infrastructure as a Service):** Provides virtualized computing resources like servers, storage, and networking. Example: Amazon EC2.
* **PaaS (Platform as a Service):** Provides a platform to develop, run, and manage applications without managing infrastructure. Example: AWS Elastic Beanstalk.
* **SaaS (Software as a Service):** Delivers fully managed applications over the internet. Example: Amazon Chime, WorkMail.

**2. What are the advantages of cloud computing?**

* Pay-as-you-go pricing
* Elasticity and scalability
* High availability and reliability
* Security at scale
* Global reach

**3. What is an AWS Region?**
A physical location worldwide where AWS has multiple data centers.

**4. What is an Availability Zone (AZ)?**
One or more discrete data centers within a Region, with independent power, networking, and connectivity.

**5. What are all the AWS Regions?**
There are 30+ Regions globally (e.g., US East (N. Virginia), Europe (Ireland), Asia Pacific (Tokyo)). [Exact list is updated regularly on AWS Global Infrastructure.]

**6. What are the categories in which the AWS services are grouped?**

* Compute
* Storage
* Database
* Networking & Content Delivery
* Security, Identity & Compliance
* Analytics
* AI/ML
* Developer Tools
* Management & Governance, etc.

**7. What is the difference between object storage and block storage?**

* **Object storage:** Stores data as objects (metadata + data), highly scalable, ideal for unstructured data. Example: Amazon S3.
* **Block storage:** Stores data in fixed-size blocks, low latency, suitable for databases and OS. Example: Amazon EBS.

**8. What are two AWS compute services, and what do these services do?**

* **Amazon EC2:** Virtual servers in the cloud.
* **AWS Lambda:** Serverless compute to run code without provisioning servers.

**9. What are two AWS storage services, and what do these services do?**

* **Amazon S3:** Scalable object storage.
* **Amazon EBS:** Block storage for EC2 instances.

# **Part 2 – AWS Cloud Foundations**

**1. What is the AWS shared responsibility model?**

* AWS manages **security of the cloud** (infrastructure).
* Customer manages **security in the cloud** (applications, data, configurations).

**2. What is an AWS Identity and Access Management (IAM) role?**
A set of temporary permissions that can be assumed by entities (users, apps, services).

**3. What is an IAM policy?**
A JSON document that defines permissions for IAM users, groups, or roles.

**4. What is an Amazon Machine Image (AMI)?**
A preconfigured template (OS + software) used to launch EC2 instances.

**5. What are the different Amazon EC2 instance types, and what are use cases for each type?**

* **General purpose (t3, m5):** Balanced compute/memory.
* **Compute optimized (c5):** High-performance compute (gaming, HPC).
* **Memory optimized (r5, x1):** Large in-memory databases.
* **Storage optimized (i3, d2):** High-speed storage (data warehousing).
* **Accelerated computing (p3, g4):** GPU-intensive workloads (ML, graphics).

**6. What is a virtual private cloud (VPC)?**
A logically isolated network in AWS where you can launch resources.

**7. What is the difference between a public and a private subnet?**

* **Public subnet:** Accessible from the internet via an internet gateway.
* **Private subnet:** Not directly accessible from the internet.
